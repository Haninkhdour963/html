# html
📅 My Daily Schedule
This repository contains a simple HTML table-based schedule showcasing my daily routine as a programmer.
It’s a straightforward, beginner-friendly example for practicing HTML table elements, row/column spans, and basic page structure.

🚀 Features
Semantic HTML with <!DOCTYPE html> and <html lang="en"> declaration.

A bordered table displaying time slots and activities.

Use of:

<th> for table headers.

<td> for table data.

rowspan and colspan for merging cells.

<pre> for preserving spacing/alignment.

Represents a real-life daily schedule of a programmer.

  🎯 Purpose
Practice HTML tables for structuring data.

Demonstrate rowspan, colspan, and <pre> usage.

Build a simple yet clean HTML document without CSS or JS.

🛠 Future Improvements
Add CSS styling for better design and mobile responsiveness.

Replace <pre> spacing with proper CSS padding and alignment.

Make an interactive schedule using JavaScript.
